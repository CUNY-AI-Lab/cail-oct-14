Handling Requests

  • Faculty, students and librarians bring us their problems
  • We first check whether an existing tool fits
  • If none does, we offer model access, a workshop, or a new tool
  • We use what we learn to choose models and plan new tools
Stefano Morello

Services We Buy and Run

  • We buy inference and hosting from outside providers
  • We use only providers that don’t keep or train on what people send
  • We run a little hardware of our own, including a transcription server
  • We run the gateway people use to reach those providers

Gateway Design Decisions

  • We keep no prompts or responses at the Gateway, and neither do the providers
  • We offer only open-weight models
  • Each person gets a monthly allowance
  • We run it on Cloudflare Workers and pay per request
Stephen Zweibel

Agent Studio and Site Studio

  • People give the agent a whole task to do
  • Agent Studio for research with sources, files and drafts
  • Site Studio for academic websites, with a preview before publishing
  • The same login and allowance as everywhere else
