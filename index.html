Handling Requests

  • Faculty, students and librarians bring us their problems

Services We Buy and Run

  • We buy inference and hosting from outside providers
  • We use only providers that don’t keep or train on what people send
  • We run a little hardware of our own, including a transcription server
  • We run the gateway people use to reach those providers

Gateway Design Decisions

  • We keep no prompts or responses at the Gateway, and neither do the providers
  • We offer only open-weight models
  • Each person gets a monthly allowance
  • We run it on Cloudflare Workers and pay per request
We made each of these choices. A vendor would make them differently. On Workers we pay only for the requests that come in. An always-on container on AWS, which is how the Sandbox runs, costs money every hour whether or not anyone is using it.

CAIL Pi

  • Pi is an open-source coding agent that runs in a terminal
  • One command installs it and connects it to the Lab’s models
  • People use their own Lab key and monthly allowance
  • We teach with it in this fall’s vibe-coding workshops
Stefano maintains CAIL Pi and can take questions on it. The released version (0.3.0) is one npx command that installs Pi and asks for the person's Lab API key. A version that signs in with CUNY Login in the browser is in progress and not released. The terminal is the barrier for many people; Agent Studio and Site Studio offer agent help in the browser instead. Closing: We can connect the Gateway to any provider that meets these rules, including a public one. Empire AI is the obvious candidate in New York. Keep this to a sentence or two.
